Machine learning aplicado al análisis de señales ECG

Caracterización de bloqueos auriculoventriculares con aprendizaje máquina basado en variables predictivas.

98registros clínicos
7variables predictivas
100repeticiones Montecarlo
86,5 %accuracy del KNN en test
1

Datos y preparación

Parto de 98 registros clínicos ECG unificados en una base de datos estructurada. División estratificada 70/15/15 y normalización. Evaluación con 100 repeticiones mediante el método de Montecarlo, con una nueva partición aleatoria en cada una, para no depender de una sola partición.

2

Selección de variables

Análisis estadístico (Mann-Whitney y χ²) para quedarme con 7 variables interpretables y clínicamente relevantes. PR_REDCap resultó la de mayor capacidad discriminativa.

3

Modelos y resultados

Regresión logística, más interpretable, frente a KNN. El KNN obtuvo el mejor rendimiento global, con una accuracy media del 86,5 % en test.

4

Demostrador web

Aplicación interactiva donde se introducen las siete variables y se obtiene la clasificación de ambos modelos. Finalidad ilustrativa, no diagnóstica.
